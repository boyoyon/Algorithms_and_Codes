MDS: Multi Dimensional Scaling
多次元尺度構成法

なにものか?

複数の点の、お互いの距離情報から二次元や三次元の配置(マップ)を復元するもの。

入力

近接行列 (proximity matrix)：お互いの距離情報
・正方行列　　：総当たりの組み合わせの距離なので。
・対象行列　　：A から B までの距離と B から A までの距離は同じ。
・対角成分は０：自分から自分までの距離なので。

(点の数)×(点の数)の行列を扱うので、点の数が多いと使いづらくなる。
別名 EDM: Euclidean Distance Matrix (ユークリッド距離行列)

出力

二次元または三次元の配置(マップ)

・回転しても、裏返しても距離は変わらないので、結果には回転、裏返しのあいまいさがあり、経度、緯度のような絶対的な出力にはならない。

用途

これが何の役に立つのか？

  • (1) 多次元データの可視化 (データ・サイエンス)
    ・距離は多次元の点でもで定義されるので、二次元や三次元のマップに次元を下げて、可視化することができる。
    ・高次元データを扱う識別器のクラス間の分離具合などを視覚化し確認する。
    ・この用途では、t-SNE, UMAP, などが使われることが多いかも。

  • (2) 抽象的な距離をマップ化して視覚化する (心理学, マーケティング, 不動産, 政策, ･･･)
    ・人と人の心理的距離を数値化し、マップで表示する。
    ・各種製品に対する顧客の感想(爽快さ、値ごろ感、など)を数値化してもらい、それらを高次元ベクトルとして、製品の位置づけをマップ化する
    ・各都市の犯罪発生率、･･･ を数値化し、それらを高次元べクトルとして、各都市をマップ化する

  • (3) 無線端末の配置を視覚化する (ロボット, 消防, ･･･)
    ・お互いの電波強度から距離は推定できる。
    ・電波が届かない端末間の扱いをどうするか工夫する必要がある。
    　●『DynoLoc: 動的な屋内環境でのインフラストラクチャフリーの RF トラッキング』 (2022)
    • 　　相対的な位置特定のための既存のソリューション(ユークリッド距離行列(EDM) を使用する手法など) は、ネットワークトポロジが完全グラフであり、すべての距離推定が利用可能で正確な場合にはうまく機能します。ただし、実際の展開でこのように機能しない場合、精度が著しく低下する可能性があります。
    • 　　グラフのエッジの重みは、隣接行列(別名ユークリッド距離行列 EDM)の形式で維持され、各エントリは2つのノード間の測定された距離を表します。次に、多次元スケーリング(MDS)と呼ばれるアプローチがEDMマトリックスに適用され、EVD (固有値分解) によって 2D直交座標空間にノードが埋め込まれます(つまり、相対的な位置特定)。
    • 　　不完全なトポロジ全体に EDM 補完技術を適用する代わりに、kコアサブグラフのグラフ剛性構造を利用。

    　

実装

scikit-learn に MDS を実行してもらう

近接行列(の各要素を2乗したもの)を与えれば, 位置関係に変換してくれる。
(data/mds/src/mds_by_scikit-learn.py) 


import numpy as np
import matplotlib.pylab as plt
from sklearn import manifold

# 近接行列(の各要素を2乗したもの)

P = np.array([
    [0.00, 1.00, 1.73, 2.00, 1.73, 1.00],
    [1.00, 0.00, 1.00, 1.73, 2.00, 1.73],
    [1.73, 1.00, 0.00, 1.00, 1.73, 2.00],
    [2.00, 1.73, 1.00, 0.00, 1.00, 1.73],
    [1.73, 2.00, 1.73, 1.00, 0.00, 1.00],
    [1.00, 1.73, 2.00, 1.73, 1.00, 0.00]])

P2 = P ** 2 # 各要素を2乗

N = P2.shape[0]

# MDSオブジェクトの作成
mds = manifold.MDS(n_components = 2,  dissimilarity = 'precomputed')

# MDSの実行
loc = mds.fit_transform(P2)

# MDS実行結果の表示
for i in range(N):
    plt.plot([loc[i-1][0], loc[i][0]], [loc[i-1][1], loc[i][1]])

plt.show()

Numpy を使って MDS を実装する

wikipeia MDS に古典MDS のステップが載っているので, Numpy を使ってその通りに実装してみる。

  • STEP.1
    各要素を2乗した近接行列を用意する。
    \(P^{(2)}=[p_{ij}^2]\)

  • STEP.2
    センタリング行列 \(C=I-\frac{1}{2}J_n\) を使ってダブルセンタリング \(B=-\frac{1}{2}CP^{(2)}C\) を実行する。
    ここで \(n\) は点の数, \(I\) は \(n×n\) の単位行列, \(J_n\) は \(n×n\) は要素がすべて1の行列。

  • STEP.3
    \(B\) の固有値 \(\lambda_1, \lambda_2, \lambda_3, \cdots\) から大きいものを \(m\) 個と, それに対応する固有ベクトル \(m\) 個を求める。

  • STEP.4
    \(X=E_m\Lambda_m^{1/2}\) を求める。
    ここで \(E_m\) は \(m\) 個の固有ベクトルからなる行列, \(\Lambda_m\) は \(B\) の \(m\) 個の固有値の対角行列。
    ※ これは縦横比の調整。以下のコードでは実装していない。

(data/mds/src/mds_by_numpy.py) 



import numpy as np
import matplotlib.pylab as plt

# STEP1: 近接行列の各要素を2乗したものを用意する

P = np.array([[0.00, 1.00, 1.73, 2.00, 1.73, 1.00],
    [1.00, 0.00, 1.00, 1.73, 2.00, 1.73],
    [1.73, 1.00, 0.00, 1.00, 1.73, 2.00],
    [2.00, 1.73, 1.00, 0.00, 1.00, 1.73],
    [1.73, 2.00, 1.73, 1.00, 0.00, 1.00],
    [1.00, 1.73, 2.00, 1.73, 1.00, 0.00]])

P2 = P ** 2 # 各要素を2乗

N = P2.shape[0]

# STEP2: センタリング行列を使ってダブルセンタリングを実施する。

C = np.eye(N) - np.ones((N,N))/2 # センタリング行列

B = - 1/2 * C * P2 * C # ヤング・ハウスホルダー変換 (ダブルセンタリング)

# STEP3: 固有値分解

w,v = np.linalg.eig(B)
indices = np.argsort(w)
x = indices[-1] # 1番大きい固有値の index をx軸とする
y = indices[-2] # 2番目に大きい固有値のindx を y軸とする

# MDS実行結果の表示
for i in range(N):
    plt.plot([v[i-1][x], v[i][x]], [v[i-1][y], v[i][y]])

plt.show()

(実行結果)

ヤング・ハウスホルダー変換 (Young-Householder Transformation)

Google AIモードによれば･･･

多変量解析の手法の一つである多次元尺度構成法（MDS）において、「個体間の距離データ」を「内積行列」へと変換する数学的な手続きのこと。
1938年にG. YoungとA. S. Householderによって提案された定理に基づいている。
